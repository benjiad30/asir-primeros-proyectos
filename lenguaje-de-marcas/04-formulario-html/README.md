# Formulario HTML de inscripción

Formulario de inscripción para un grupo scout, hecho solo con HTML y estilos en línea. Para verlo basta con abrir `index.html` en el navegador.

## Elementos que se usan
- **Organización:** `fieldset` y `legend` para separar los bloques (datos del menor, del tutor, información adicional y acceso).
- **Campos de texto:** `text`, `date`, `tel`, `email` y `password`, todos con `required`.
- **Selección:** lista desplegable (`select`), casillas (`checkbox`) para las aficiones y botones de opción (`radio`) para la periodicidad de pago.
- **Otros:** `textarea` para observaciones, vídeo incrustado con `iframe`, enlaces externos e imágenes.
- **Botones:** `submit` y `reset`.

El formulario no envía datos a ningún sitio: es una práctica de maquetación.
