# ASIR · Primeros proyectos

Prácticas del primer semestre del CFGS **Administración de Sistemas Informáticos en Red (ASIR)**.
Cada carpeta es una práctica con su código o su documentación paso a paso y las capturas de cómo se hizo.

## Contenido

### Lenguaje de Marcas y Sistemas de Gestión de Información
| Práctica | Qué se trabaja |
|---|---|
| [01 · XML bien formado](lenguaje-de-marcas/01-xml-bien-formado) | Estructura de documentos XML y uso de entidades (`&amp;`, `&lt;`, `&gt;`, `&quot;`) |
| [02 · Validación con DTD](lenguaje-de-marcas/02-validacion-dtd) | DTD externos, atributos enumerados, `ID`, `IDREF` e `IDREFS` |
| [03 · Validación con XSD](lenguaje-de-marcas/03-validacion-xsd) | Esquema XSD con tipos simples y restricciones por patrón |
| [04 · Formulario HTML](lenguaje-de-marcas/04-formulario-html) | Formulario de inscripción con distintos tipos de campo |

### Fundamentos de Programación
| Práctica | Qué se trabaja |
|---|---|
| [01 · Pseudocódigo en PSeInt](fundamentos-programacion/01-pseint) | Bucles `Repetir` y `Para`, acumuladores y condicionales |
| [02 · Listas en Python](fundamentos-programacion/02-python-listas) | Métodos de listas: `count`, `remove`, `insert`, `sort` |

### Implantación de Sistemas Operativos
| Práctica | Qué se trabaja |
|---|---|
| [01 · Windows en máquina virtual](sistemas-operativos/01-windows-en-maquina-virtual) | Instalar Windows 10 x64 en un Mac con Apple Silicon usando UTM (emulación) |
| [02 · Usuarios, grupos y permisos](sistemas-operativos/02-usuarios-grupos-permisos) | Cuentas locales, grupos, permisos NTFS y directivas de seguridad |
| [03 · Administración remota](sistemas-operativos/03-administracion-remota) | IP fija, archivo hosts, optimización, `arp`, SSH, `tasklist` y `taskkill` |

## Herramientas
PSeInt · Python 3 · Visual Studio Code · xmllint · UTM / QEMU · Windows 10 · macOS Terminal
